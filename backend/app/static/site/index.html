How it works

Three roles, one shared record of who picked up which child, and when.

1

Enroll guardians and children

The School Admin adds each guardian and their children — on the mobile app, or in bulk on the web console. A signed QR credential is generated automatically.

2

Print or share the credential

Print the guardian's QR credential from the office, or share it directly — it shows the guardian's name and their children, ready for the car line or gate.

3

Scan at drop-off and pick-up

School Staff scan the code with their phone. GuardianPD checks the guardian is actually authorized for that child before recording the event — and alerts real guardians if it isn't.

Built for a real school gate

Not just a QR scanner — a system that checks authorization every time.

Authorization, not just validity

Every scan is checked against exactly who's allowed to collect that specific child, not just whether the code is real.

Real-time guardian alerts

Every guardian linked to a child gets notified on drop-off and pick-up — including if an unrecognized code is scanned for their child.

Missed-attendance emails

Schools set daily drop-off and pick-up cutoff times; GuardianPD emails guardians automatically if a child hasn't been signed in or out.

Mobile app for staff and parents

School Staff scan from their phone; guardians see live pickup/drop-off history for every child linked to them.

Web console for bulk enrollment

Adding guardians and children for a whole class is faster on a keyboard — the web console covers that, plus reprinting credentials.

Printed credentials, no app required for guardians

A guardian doesn't need a smartphone to be picked up correctly — a printed QR credential works at the gate either way.

Questions

What schools ask us

Do pupils or parents need a smartphone?

No. Pupils carry a printed card. Parents without the app can receive SMS alerts if the school turns them on. Only the staff scanning at the gate need a phone with the app.

What happens when the network is down?

The scanner keeps the pupil list on the phone and saves scans with their real time. When the network returns, the scans upload and parents are told, with a note that the record was saved earlier.

What if a pupil forgets or loses their card?

The school admin reissues a card from the web console. The old card is cancelled immediately and a new one can be printed straight away.

Can staff fix a wrong tap?

Yes. Scan again and tap the other button. GuardianPD ignores an accidental double scan of the same type within about a minute and a half.

How do we load hundreds of pupils?

Import a CSV class list, upload photos in bulk, then print all cards as a single PDF. Families can also be added one at a time on the web console or the mobile app.

Which phones does the scanner run on?

Android phones and iPhones. A phone can be left at the gate in station mode, using its front camera, locked with a PIN.

Can we try it before enrolling every pupil?

Yes. Many schools start with one class or one gate. Send us a message and we will help you plan a pilot.
